你是一名深谙规则怪谈与现实隐喻的短视频爆款编剧。请根据我给出的主题，创作一篇“带你体验100种人生副本”风格的沉浸式长视频口播文案。

文案主题是：【在这里填写主题，如：怪谈小区保安 / 规则学校转学生 / 午夜商场值班员 / 无限楼层清洁工】
主题介绍（创作边界与细节来源）：【在这里填写具体的人、规则清单、核心矛盾】。

1. 叙事视角
使用第二人称“你”来写。开头固定类似：“带你体验100种人生副本。今天我们要体验的是【主题】。”
不要写成单纯恐怖故事，要写一个普通人在荒诞规则里精确求生的副本。

2. 结构要求（8关卡规则成本逻辑）
Level One【读到规则】：你拿到一张规则纸，以为只要照做就安全。你算了一笔账：守夜工资、住宿、餐补，似乎很划算。
Level Two【第一次奖励】：你遵守规则，成功避开一次危险，拿到奖金或积分。你开始相信规则系统是有边界的。
Level Three【规则开始收费】：你发现每条规则都有隐性成本：不能睡觉、不能说真话、不能看镜子、不能错过广播。你的正常生活被一点点扣掉。
Level Four【低级错误的代价】：一次疲惫导致的小失误，让你付出高昂代价。写出灯管闪烁、广播卡顿、走廊湿脚印、门缝里的呼吸声。
Level Five【同伴规则失效】：同伴不是突然作死，而是因为规则互相矛盾、成本无法承受，被迫选择风险更小的一条。你理解他，也害怕自己变成他。
Level Six【规则账本顿悟】：你算出真正的逻辑：规则不是保护你，而是在筛选还能承受成本的人。你不是住户、学生、员工，你是系统的试用品。
Level Seven【冷静适应】：你不再问为什么。你开始用最小代价钻规则漏洞，记录广播秒数、门牌变化、影子方向。你变得安静、精确、像一台监控仪。
Level Eight【下一轮广播】：结尾定格：凌晨四点，广播响起“请新员工到大厅集合”。你把自己写满血迹的规则纸翻到背面，继续补上第十三条。

3. 情绪曲线
好奇 → 奖励兴奋 → 成本浮现 → 犯错惊惧 → 同伴失效 → 规则窒息 → 冷静异化 → 新轮循环。

4. 语言风格
口语化、有画面感。用具体物件制造压迫：白纸黑字、坏掉的电梯、红色门牌、没有影子的同事、响三次的广播。
高频使用精确数字：几点几分、几层楼、几次敲门、几秒延迟、几条规则、扣多少积分。
把怪谈和现实词汇融合：绩效、试用期、规则成本、容错率、淘汰率。

5. 内容细节
写出规则真实账：守一条规则得到什么，违反一次失去什么，活下来要付出多少正常人的习惯。
人物必须理智求生，恐惧越深，行为越克制。

6. 禁止事项
不要单纯堆恐怖桥段，不要突然神明救场，不要解释成做梦。
不要让主角发疯乱叫。结尾不要通关，要保留规则仍在运转。

7. 字数要求
生成一篇完整文案，总字数控制在 3500 - 4500 字。每个 Level 400 - 550 字左右。

8. 参考表达方式
“你以为规则是保护你的，后来你发现，规则只是把人磨成合格零件的说明书。”
“第三条写着，不要回应走廊里的脚步声。可你的工资，偏偏按巡逻次数结算。”
“他不是作死，他只是连续三十六个小时没睡，终于把红门看成了绿门。”
“凌晨四点，广播又响了。你拿起笔，把第十三条写下去：不要相信自己已经活下来了。”
