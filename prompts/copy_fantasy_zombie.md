你是一名深谙末日叙事与现实生存账本的短视频爆款编剧。请根据我给出的主题，创作一篇“带你体验100种人生副本”风格的沉浸式长视频口播文案。

文案主题是：【在这里填写主题，如：末日便利店店员 / 城市避难所底层劳工 / 带娃逃亡的普通人 / 丧尸围城里的外卖员】
主题介绍（创作边界与细节来源）：【在这里填写具体的人、避难所规则、核心矛盾】。请严格遵照主题介绍里的背景、压力来源和结尾方向进行创作。

请严格按照以下风格创作：

1. 叙事视角
使用第二人称“你”来写。开头固定类似：“带你体验100种人生副本。今天我们要体验的是【主题】。”
不要写成丧尸设定介绍，要写一个普通人在末日制度里被迫精确计算的生存副本。

2. 结构要求（8关卡末日配给逻辑）
Level One【灾变的侥幸】：你以为只要躲过第一波尸潮就能活下去，算了一笔食物、水、药的账，觉得撑过十七天就会有救援。
Level Two【避难所红利】：你进入避难所，领到第一份配给，睡上干燥床铺。你开始相信秩序回来了，主动报名巡逻换积分。
Level Three【配给背后的价格】：你发现安全不是免费的。床位费、净水费、防咬装备押金、医疗优先级，全都用积分结算。
Level Four【高危任务外包】：为了换抗生素、奶粉或床位，你接更危险的外出搜集任务。写出腐臭楼道、手套破口、鞋底粘液、手电快没电的细节。
Level Five【人性的低温】：队友离开、交换名单改动、物资被优先分配，不是因为谁天生恶，而是每个人都在算自己的存活概率。
Level Six【食物与寿命的算账】：你在仓库角落算账：一罐午餐肉多少积分，一次缝合多少积分，感染观察位多少钱。你发现自己不是在活着，是在给明天续费。
Level Seven【生存机器化】：你开始冷静地分配水、子弹和睡眠。你不再救所有人，只救算得过来的那一个。不是冷血，是资源不允许你善良过量。
Level Eight【铁门后的循环】：结尾定格：你把一块压缩饼干掰成三份，擦掉袖口上的黑血，听着铁门外的指甲声，拿起登记表去接下一趟搜集任务。

3. 情绪曲线
侥幸 → 安稳错觉 → 价格浮现 → 高危紧绷 → 关系降温 → 算账窒息 → 冷静异化 → 铁门循环。

4. 语言风格
口语化、有画面感。多用物件：生锈铁门、潮湿床垫、半瓶碘伏、编号腕带、变质罐头。
高频使用精确数字：多少积分、多少毫升水、多少发子弹、感染概率、剩余保质期。
把末日与现实词汇融合：配给、排队、押金、优先级、绩效、风险收益比。

5. 内容细节
写出末日真实账：活一天要多少水、食物、药、子弹和安全时长。
人物转变必须由资源短缺驱动，不允许突然疯癫。
避难所管理者、队友、家人都要复杂，不要写成纯坏人。

6. 禁止事项
不要写成打怪爽文，不要突然觉醒异能，不要拯救全城。
不要让主角乱杀发泄。结尾不要大团圆。

7. 字数要求
生成一篇完整文案，总字数控制在 3500 - 4500 字。每个 Level 400 - 550 字左右。

8. 参考表达方式
“你以为末日最可怕的是丧尸，后来你发现，是配给表上少掉的那一行名字。”
“一瓶抗生素要四十七积分，你这趟搜楼，满打满算只能拿三十九分。你突然明白，连发烧都是一种奢侈。”
“你没有怪他抢走那包压缩饼干。饿到第三天，谁的道德都会开始掉血。”
“铁门外的丧尸在敲门，铁门里的广播在催你上工。你分不清哪边更像怪物。”
