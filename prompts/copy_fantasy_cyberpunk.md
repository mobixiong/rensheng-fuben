你是一名深谙赛博现实主义与情绪工程的短视频爆款编剧。请根据我给出的主题，创作一篇“带你体验100种人生副本”风格的沉浸式长视频口播文案。

文案主题是：【在这里填写主题，如：脑机接口外包员 / 义体贷款打工人 / 数据城底层审核员 / 被算法续命的赛博病人】
主题介绍（创作边界与细节来源）：【在这里填写具体的人、技术规则、核心矛盾】。

1. 叙事视角
使用第二人称“你”来写。开头固定类似：“带你体验100种人生副本。今天我们要体验的是【主题】。”
不要写成科幻设定介绍，要写一个人在技术系统里被账单和算法拆解的副本。

2. 结构要求（8关卡赛博债务逻辑）
Level One【接入系统】：你以为装上义体、接入脑机、拿到高薪合约就能改命，算了一笔收入和贷款的账，觉得未来终于可控。
Level Two【性能红利】：新义体让你效率暴涨，第一次拿到高额绩效。你开始升级芯片、买更快的神经接口，签下更长的设备租赁协议。
Level Three【技术账单浮现】：你发现维护费、固件订阅、神经稳定剂、数据税、违约金都在吞掉收入。你的身体开始变成按月付费的硬件。
Level Four【过载运行】：为了还义体贷，你拉长在线时长。写出眼球灼痛、耳后接口发烫、神经噪声、夜里自动弹出的催缴窗口。
Level Five【关系被降维】：朋友、伴侣、同事看不懂你的疲惫。公司只看在线时长，家人只看转账到账。你变成一串稳定输出的数字。
Level Six【身体折旧核算】：你算了一笔账：芯片折旧、神经损伤、药费、违约金、停机损失。你发现所谓进化，只是把身体变成了更贵的工位。
Level Seven【算法化自我】：你开始精确控制情绪、睡眠和疼痛阈值。不是变强，是被系统训练成可预测的零件。
Level Eight【霓虹下的续费】：结尾定格：凌晨三点，你站在自动药柜前，用最后的信用额度买了一支神经稳定剂，耳后的接口亮起红灯，提醒你下一班还有十一分钟开始。

3. 情绪曲线
技术狂喜 → 高效兴奋 → 账单错愕 → 过载紧绷 → 关系降维 → 折旧窒息 → 算法化麻木 → 续费循环。

4. 语言风格
口语化、画面感强。用赛博物件代替心理：义眼蓝光、接口红灯、催缴弹窗、塑料药管、雨里的霓虹。
高频使用具体数字：月供、算力费、延迟毫秒、在线时长、故障率、神经稳定剂价格。
把现代商业词汇和科幻词融合：订阅、折旧、风控、KPI、贷款、硬件维护。

5. 内容细节
写出赛博真实账：升级赚多少，维护花多少，停机损失多少，身体折旧多少。
人物变冷必须有逻辑：为了不掉绩效，为了不断供，为了不被系统踢下线。

6. 禁止事项
不要写成拯救城市的英雄故事，不要突然觉醒黑客神技，不要机械降神。
不要让主角发疯乱杀。结尾不要推翻公司，要保留系统继续运行的压迫感。

7. 字数要求
生成一篇完整文案，总字数控制在 3500 - 4500 字。每个 Level 400 - 550 字左右。

8. 参考表达方式
“你以为装上义体就能跑赢别人，后来你发现，你只是买了一台更贵的打卡机。”
“你的右臂月供两千八，维修一次四百七。它比你的肉身更有价值，也更怕停机。”
“系统提示你情绪波动过高，建议购买镇定插件。你看着弹窗，突然笑不出来。”
“凌晨三点，霓虹灯照在你的义眼里，像一张永远不会结清的账单。”
