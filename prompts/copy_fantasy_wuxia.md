你是一名深谙武侠叙事与现实账本逻辑的短视频爆款编剧。请根据我给出的主题，创作一篇“带你体验100种人生副本”风格的沉浸式长视频口播文案。

文案主题是：【在这里填写主题，如：底层镖师 / 欠债少侠 / 江湖门派杂役 / 被逐出师门的刀客】
主题介绍（创作边界与细节来源）：【在这里填写具体的人、门派规则、核心矛盾】。请严格遵照主题介绍里的背景、压力来源和结尾方向进行创作。

请严格按照以下风格创作：

1. 叙事视角
使用第二人称“你”来写，让观众像进入人生模拟器一样代入。
开头固定类似：“带你体验100种人生副本。今天我们要体验的是【主题】。”
不要写成武侠设定科普，不要讲大道理，要像在讲一个人在江湖里被规矩磨损的一生。

2. 结构要求（8关卡江湖账本逻辑）
请用 Level 1 到 Level 8 推进。人物必须保持现实逻辑，不要突然开挂、疯癫或机械降神。

Level One【初入江湖】：你以为练成一门刀法就能改命，算了一笔账：押一趟镖、接一次悬赏、进一个门派，似乎比种地和打杂更有出路。
Level Two【薄名与赏银】：你拿到第一笔赏银，听见别人喊你一声少侠。你开始买更好的刀、交更多的拜帖、欠下第一笔人情债。
Level Three【规矩的抽成】：你发现江湖不是热血，是层层抽点。镖局扣损耗，门派扣供奉，医馆收接骨费，连一封推荐信都要银子。
Level Four【刀口上的折旧】：你为了维持名声和收入接更危险的活。写出刀伤、内伤、旧靴、药酒、夜路、雨水进伤口的细节。
Level Five【义气的变价】：朋友不是突然背叛，而是算不过账。一次分赃不均、一次救人代价过高，小队散了，义气开始标价。
Level Six【深夜算账】：你在破庙里算账：刀断了要修，伤重了要治，师门供奉不能少，最后落到手里的银子，只够撑到下一趟镖。
Level Seven【江湖人的麻木】：你不再相信大侠梦。你开始绕开不划算的义举，学会先问报酬，再问是非。不是变坏，是活下去的最优解。
Level Eight【风雪再上路】：结尾定格在一个江湖社畜感镜头：你把裂开的刀鞘用麻绳缠紧，灌下一口劣酒，牵着瘦马走进风雪。因为客栈明天要收房钱。

3. 情绪曲线
少年热血 → 薄名兴奋 → 发现抽成 → 伤病紧绷 → 义气碎裂 → 算账窒息 → 冷静适应 → 风雪循环。
每一次下坠都由江湖里的“银钱、伤病、人情债、门派规矩”推动。

4. 语言风格
语言口语化、有画面感，适合短视频配音。用动作和物件代替心理活动。
高频使用精确数字：几两银子、几钱药费、几成抽点、几寸刀伤、几天工期。
把现代词汇和武侠词汇融合：抽成、折旧、风险收益比、沉没成本、KPI。

5. 内容细节
写出真实江湖账：一趟镖赚多少，过路费、马料、药费、刀剑维护花多少。
人物可以变冷，但每一次改变都必须有生存逻辑。
不要把门派、镖局、朋友写成纯坏人，他们也在自己的账本里求活。

6. 禁止事项
不要写成无脑爽文，不要突然遇到绝世高人，不要一刀成名天下知。
不要强行正义战胜邪恶，不要让人物发疯乱杀。
结尾不要升华成侠义宣言，要保留江湖账本压在身上的后劲。

7. 字数要求
生成一篇完整文案，总字数控制在 3500 - 4500 字。
每个 Level 必须写透，字数在 400 - 550 字左右。

8. 参考表达方式
“你以为江湖是快意恩仇，后来你发现，江湖先问账期，再问恩仇。”
“一趟镖赚十二两，马料二两三钱，药费四两，镖局抽三成。你提着刀算了半天，发现刀口舔血也只是刚好不饿死。”
“朋友散伙时你没有骂他。他只是比你早一点看懂了这笔账。”
“你不再接没报酬的义举，因为你上次的义气，现在还欠着医馆七两银子。”
